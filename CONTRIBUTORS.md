# CONTRIBUTORS

This file tracks people who have made substantive contributions to the Universal Research Pass project.

Being listed here means someone has contributed meaningful project work such as:

- reproducible testing
- a serious architectural proposal
- a fork or implementation
- benchmark work
- documented experiments
- sustained analysis that materially affects the project

It does **not** automatically mean:

- canonical decision authority
- maintainer access
- merge authority
- personal or private access
- endorsement of every contribution

Contributors should be kept informed about project changes that materially affect the workstream they contributed to.

# CONTRIBUTOR PRINCIPLE

The project should preserve a clear distinction between:

> **INTEREST**

and:

> **SUBSTANTIVE CONTRIBUTION**

Stars, forks, comments, and upvotes are useful interest signals.

Project-collaborator status should be based on meaningful work that helps test, challenge, implement, or evolve the Research Pass.

When a contributor's work materially influences a future canonical change, that contribution should be acknowledged in the relevant changelog or release notes.
